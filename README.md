# Dr. T.V.G. Shri Prakash - Academic & Research Portfolio

A modern, responsive, and interactive academic portfolio website for **Dr. T.V.G. Shri Prakash**, Associate Professor of Mathematics, researcher in Graph Theory (S-Valued Graphs), and Life Member of the Ramanujan Mathematical Society.

?? **Live Portfolio (GitHub Pages)**: Can be activated directly under repo Settings -> Pages -> Deploy from branch `main`.

---

## ?? Key Features

- **Executive Academic Hero**: Framed portrait, verified academic badges, and key metrics dashboard (21+ Years Experience, 11 Publications, 11 Conferences, 8+ Courses).
- **Interactive Graph Theory Canvas**: Dynamic background particle animation visualizing nodes (vertices $V$) and connecting lines (edges $E$) that react to mouse hover.
- **AI ScholarBot (Academic Companion)**: Interactive conversational assistant answering questions about research, papers, courses, and career.
- **AI Research Paper Explainer**: One-click layman summaries explaining advanced pure mathematics theorems in plain English, with theoretical breakthroughs and real-world applications.
- **Searchable Publications Hub**: Real-time keyword search and category filters across all 11 peer-reviewed international papers with one-click APA/IEEE citation copying and BibTeX code generation.
- **21+ Years Career Timeline**: Filterable chronological record of higher education appointments (SASTRA University, Sri Meenakshi Vidiyal, Kurinji, Mahalakshmi) and foundational teaching.
- **Courses Handled & Pedagogy**: Curriculum breakdowns for Engineering Mathematics I-III, Probability, Random Processes, Numerical Methods, and Graph Theory.
- **Education & Credentials**: Ph.D (Madurai Kamaraj University), M.Phil, M.Sc, B.Ed, B.Sc, and Ramanujan Mathematical Society Life Membership.
- **Light & Dark Theme Toggle**: Elegant pastel palette with smooth transition to a gentle slate/navy dark mode.
- **Print / PDF CV Export**: Dedicated `@media print` styling that formats the page into an executive academic CV.
- **Responsible & Responsive Design**: WCAG 2.1 AA accessible, fluid typography (`clamp()`), and optimized for desktop, tablet, and mobile devices.

## ?? Quick Start / Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Madhu192005/tvgportfolio.git
   cd tvgportfolio
   ```

2. **Run locally**:
   Double-click `index.html` to open directly in any modern browser, or serve via a local server:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`.

---

## ?? Deploy to GitHub Pages

To make the portfolio live on the web for free:
1. Go to your GitHub repository: `https://github.com/Madhu192005/tvgportfolio`
2. Click **Settings** -> **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be published at: `https://madhu192005.github.io/tvgportfolio/`
