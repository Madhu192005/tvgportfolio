# Dr. T.V.G. Shri Prakash | Academic & Research Portfolio
A modern, responsive, and interactive academic portfolio website showcasing the professional journey, academic achievements, research contributions, and teaching experience of **Dr. T.V.G. Shri Prakash**, Associate Professor of Mathematics, Graph Theory Researcher, and Life Member of the Ramanujan Mathematical Society.

**Live Portfolio:** [View Academic Portfolio](https://madhu192005.github.io/tvgportfolio/)
---

## 🛠️ Technology Stack
| Technology | Purpose |
|---|---|
| HTML5 | Semantic structure and content |
| CSS3 | Styling, animations, themes, and responsive layouts |
| JavaScript | Interactive features and application logic |

| Git & GitHub | Version control and repository management |
| GitHub Pages | Free static website hosting |

---
### 1. Clone the Repository
```bash
git clone https://github.com/Madhu192005/tvgportfolio.git
```
### 2. Navigate to the Project Directory
```bash
cd tvgportfolio
```
### 3. Run the Project
**Option 1: Open directly**
Open `index.html` in any modern web browser.
**Option 2: Run using Python HTTP Server**
```bash
python -m http.server 8000
``'
Open the following URL in your browser:
```text
http://localhost:8000
```
